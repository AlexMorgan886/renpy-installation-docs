## Android Installation Workflow

### Requirements
- Android 8.0+
- Minimum 2GB RAM recommended
- 1GB+ free storage space

### Installation Steps

1. Download the official Android package.
2. Enable installation from unknown sources.
3. Install the APK file.
4. Launch once to generate internal storage folders.
5. Grant storage permissions if prompted.

### Common Android Issues

**App not installed**
- Check available storage
- Re-download the APK file
- Disable Play Protect temporarily if blocking

**Black screen on launch**
- Clear cache
- Restart device
- Ensure full download completed

---

## Windows PC Installation Workflow

### Requirements
- Windows 10 or newer
- Extract tool (7-Zip or WinRAR)

### Installation Steps

1. Download the PC ZIP package.
2. Extract the archive to a new folder.
3. Open the extracted directory.
4. Run the .exe file.
5. If blocked, select "More Info" → "Run Anyway".

### Common PC Issues

**Missing .rpyc file**
- Extraction incomplete
- Antivirus removed file

**Game not launching**
- Run as administrator
- Check antivirus quarantine
